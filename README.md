# EPC5014 Flashcards

Bilingual (English / 繁體中文) flashcard game for EPC5014 *Foundations and Processes of Learning*, Topics 1–8.

**Play:** https://noonkho.github.io/epc5014-flashcards/

- 147 questions (multiple choice and short answer), each with an explanation and slide reference.
- Spaced repetition (Leitner boxes): due cards first, wrong cards come back soon.
- Study mode (instant feedback) and Test mode (timed, results at the end).
- Filters by topic, difficulty, question type, ★ high-yield, weak cards.
- Progress is saved in your own browser only (localStorage). Use the same browser each time; private windows do not keep progress.

Single self-contained `index.html`, no external dependencies.
